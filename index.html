这是什么

一块 NFC 电子墨水牌

板子通电后初始化 NFC Type 4 Tag 与墨水屏。手机(用 NFC Tools 等 App)靠近写入一条 NDEF 消息,固件解析后立即在墨水屏上完整刷新一次——文字用 LVGL 渲染,图片走自研 XEPR 协议直接写入 framebuffer。

  • 文字:NDEF Text 记录,LVGL 显示。
  • 图片:XEPR 协议;黑白 1-bit(256×122),四色 2bpp。
  • 持久化:最近一次内容存入独立存储区,重启自动恢复。
  • 分段写入:四色大图可拆 XEPR2A/XEPR2B 两段分次写入,自动拼接 + CRC 校验。

烧录步骤

板载 SAMD11 调试器,USB 直连,用 OpenOCD 烧录

  1. 装 openocd。推荐装 PlatformIO,再装 Seeed platform(自带适配好的 openocd): 
    # 装 Seeed platform(含 openocd 与 nRF54LM20A 板配置)
pio pkg install -g -p "https://github.com/Seeed-Studio/platform-seeedboards.git"

# macOS:把 openocd 加入 PATH
export PATH="$HOME/Library/Application Support/Seeed/OpenOCD/tool-openocd/bin:$PATH"
  2. USB-C 连接板子。XIAO nRF54LM20A 的板载 SAMD11 会枚举为 CMSIS-DAP 调试器。
  3. 一键烧录。把上面的固件 hex、openocd.cfg、flash.sh(或 flash.bat)放在同一目录后运行: 
    # macOS / Linux
chmod +x flash.sh
./flash.sh xiao_nrf54lm20a_epaper_nfc_bw.hex      # 黑白
./flash.sh xiao_nrf54lm20a_epaper_nfc_4color.hex  # 四色
    # 或手动调用 openocd
openocd -f openocd.cfg \
  -c "init" \
  -c "nrf54lm20a-load xiao_nrf54lm20a_epaper_nfc_bw.hex" \
  -c "reset" -c "exit"

烧录完成后板子自动复位运行。屏幕先显示欢迎画面,随后即可用手机 NFC 写入内容。
