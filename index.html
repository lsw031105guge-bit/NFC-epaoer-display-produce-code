这是什么

一块 NFC 电子墨水牌

板子通电后初始化 NFC Type 4 Tag 与墨水屏。手机(用 NFC Tools 等 App)靠近写入一条 NDEF 消息,固件解析后立即在墨水屏上完整刷新一次——文字用 LVGL 渲染,图片走自研 XEPR 协议直接写入 framebuffer。

  • 文字:NDEF Text 记录,LVGL 显示。
  • 图片:XEPR 协议;黑白 1-bit(256×122)。
  • 持久化:最近一次内容存入独立存储区,重启自动恢复。

烧录步骤

板载 SAMD11 调试器,USB 直连,用 OpenOCD 烧录——不需要 J-Link

📖 完整手把手烧录教程(新手建议先看这个)

重要:本板自带 SAMD11 SWD 调试器,USB 线直连即可烧录,不需要外接 J-Link 或任何额外调试器。.hex 文件可以直接烧,不需要先转成其他格式。
  1. 安装 openocd(一次性)。 推荐用 PlatformIO 装 Seeed platform,它自带适配好 nRF54LM20A 的 openocd: 
    # 1) 装 PlatformIO:https://platformio.org/
# 2) 装 Seeed platform(含 openocd 与 nRF54LM20A 板配置)
pio pkg install -g -p "https://github.com/Seeed-Studio/platform-seeedboards.git"

# macOS:把 openocd 加入 PATH
export PATH="$HOME/Library/Application Support/Seeed/OpenOCD/tool-openocd/bin:$PATH"
  2. USB-C 连接板子。 板载 SAMD11 会枚举为 CMSIS-DAP 调试器,无需额外硬件。
  3. 下载本页固件与脚本。 把 .hex 固件、openocd.cfg、flash.sh(Windows 用 flash.bat)放在同一目录。
  4. 一键烧录。 
    # macOS / Linux
chmod +x flash.sh
./flash.sh xiao_nrf54lm20a_epaper_nfc_bw.hex

# Windows
flash.bat xiao_nrf54lm20a_epaper_nfc_bw.hex
    或手动调用 openocd: 
    openocd -f openocd.cfg \
  -c "init" \
  -c "nrf54lm20a-load xiao_nrf54lm20a_epaper_nfc_bw.hex" \
  -c "reset" -c "exit"

烧录完成后板子自动复位运行,屏幕先显示欢迎画面,随后即可用手机 NFC 写入内容。

常见问题

下载的 .hex 是什么?是工程文件吗?

.hex 是预编译好的机器码固件(Intel HEX 格式),是给芯片直接烧录用的"成品",不是工程文件。工程文件是源码(C/H 文件、CMakeLists、prj.conf 等),在本仓库里,给想修改或重新编译的人用。普通烧录只需 .hex。

没有 J-Link 能烧录吗?

能。XIAO nRF54LM20A 板载 SAMD11 协处理器作为 USB→SWD 调试桥,通过 OpenOCD(CMSIS-DAP)烧录,不需要 J-Link。一条 USB-C 数据线即可。

烧录报错"未找到 openocd"?

说明 openocd 没在 PATH 里。按第 1 步装好 Seeed platform 后,把它的 openocd 目录加入 PATH(macOS 路径见上方命令)。Windows 同理,把 openocd.exe 所在目录加入系统 PATH。
