# NFC ePaper 外壳 — Rev A 初步结构模型

## 已识别的供应商三维文件
- `epaper-driver-board-for-seeed-studio-xiao-v1.step`：驱动扩展板，主板主体约 25×42 mm，元件整体范围 x=-9.02~16.77, y=-3.11~4.80, z=-20.08~21.92 mm。
- `XIAO nRF54LM20A.step`：开发板，主板约 21.14×17.78 mm。由于两份厂商 STEP 的坐标系不同、XIAO 与板载母座插接姿态尚未准确对准，XIAO **尚未合并到装配图**。
- 屏幕二维工程图：外形 29.20±0.20 ×59.20±0.20 mm，厚度约 1.0±0.1 mm；122×250 像素；有效区约 23.7046×48.55 mm；排线从短边延伸，FPC 需另行定义折弯空间。

## Rev A 初步结构
- 外壳外形约 43×72 mm，前框+后壳堆叠厚度约 18.6 mm（y=-8~10.0 mm）。
- 正面开口约 24.5×50.15 mm，背面内凹屏幕座约 29.8×59.8 mm。保留边缘遮盖区域，不压显示有效区。
- 壳体外四角四个螺丝柱：坐标 x=-14.8/21.8, z=-32.5/32.5 mm；为**外壳固定**，不是驱动板螺丝孔。
- 扩展板按原始 CAD 坐标置入，预留两侧局部定位支撑。并未验证 XIAO 插接后的元件干涉。
- 右侧开口与顶部开关槽均为示意位置，USB-C 实际插头可达性、开关传动必须复核。
- 提供屏幕压片参考体，但压片缺少最终连接结构，不能视为已验证的打印卡扣方案。
- NFC 天线和磁吸充电、电池、具体按键，暂无可测三维资料，未纳入精确装配。

## 下一版必须确定
1. 扩展板是否有实际机械固定孔？如果没有，允许 PCB 边缘支撑+压片定位吗？
2. 屏幕是裸屏玻璃+FPC，还是有独立塑料转接板、保护膜和后背胶？确认 FPC 折弯半径和方向。
3. XIAO 实际在扩展板母座内的插入朝向/高度、USB-C 是否可通过侧边直接插线。
4. 电池尺寸、固定方式、开关型号和机械行程。
5. NFC 线圈尺寸、后盖安装方式；如果有磁铁，需要测定天线失谐与刷卡距离。
6. 目标打印工艺、喷嘴直径、公差，以及选择前框的屏幕安装方式（可拆卡扣/压框螺丝/胶粘）。

本版是**可打开、可迭代的概念结构 CAD**，还不是经过干涉校验的生产件。Fusion 360 可以导入 `.step`；源程序 `build.py` 在装有 CadQuery 的 Python 环境中运行生成更新的模型。
