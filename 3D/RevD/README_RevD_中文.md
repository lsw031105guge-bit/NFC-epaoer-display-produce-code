# NFC ePaper 外壳 Rev D — 以真实器件位置决定外壳开孔

## 一次打开的文件
`NFC_ePaper_RevD_OneFile_Assembly.step`：独立 STEP 装配文件（不是把所有物体布尔合成一块）。包含前框、后壳、显示玻璃名义包络、4个可拆固定片、完整供应商 ePaper 驱动板和姿态已按扩展板双排插座匹配的 XIAO nRF54LM20A STEP。Fusion 360 中 Upload 后直接打开。STL 是独立部件的试打印网格；无需一一导入才能看装配。

## 为什么从 Rev C 重做
Rev C 依靠截图猜测侧边 USB 口，XIAO 仍停在壳外；侧开关又离壁太远。这次把电子器件 STEP 当成开孔的基准，连接器向哪边，才在哪边开孔。

| 重点 | Rev D 结构处理 | 需注意 |
|---|---|---|
| 整体 | 长 72 × 宽 40 × 厚 19.6 mm；R3 圆角；较 Rev C 窄3mm、厚度少1.4mm | 仅当前结构提案 |
| 驱动板位置 | 原供应商 STEP 在 X方向平移 +5.3 mm、Z方向 -8.0 mm（开关一侧向右靠近壳壁） | 壳内 PCB 右边缘至内侧壁约0.42mm，需真机/打印验证 |
| 外部开关 | 由扩展板真实 STEP 物体（编号 71）提供几何基准，开出右侧贯穿操作窗 | 元件突出点距壳体外侧面约1.43mm；是否能轻松拨动必须实物验证；可能需要按键延长帽 |
| USB-C | XIAO STEP 按两排引脚 2.54 mm 间距旋转到扩展板母座上：XIAO USB方向朝向外壳底边（-Z）。按 USB 实体建立底边开孔 | 连接器金属前端比外壳原底边内缩5.49mm，但底边局部加深避让后，距局部凹槽内缘约1.2mm，可供插头靠近；尚需实际 USB-C 数据线验证 |
| NFC | 外壳背面（+Y 外表面）加入环形与 `NFC` 雕刻标识 | 无 NFC 贴纸的真实体积、粘贴凹位/天线避让验证，未添加磁铁/金属 |
| 扩展板固定 | 供应商 STEP 中提取的3个孔位置支撑柱 + PCB底缘两处托台，不将两侧大排针孔当作安装孔 | 这3孔须核实是否允许安装螺钉。不能盲目下螺钉 |
| 屏幕 | 29.20 ×59.20 ×1.00 mm玻璃占位；29.85×59.85mm 玻璃槽；4个可拆压片 | 没有真实FPC形状、玻璃夹持限位区与真实装配公差，不能直接压玻璃 |

## 实际几何来源
- 驱动板：`epaper-driver-board-for-seeed-studio-xiao-v1.step`，真实外形及器件。
- XIAO：`XIAO nRF54LM20A.step`，以其两排引脚/USB连接器包络定位。
- ePaper：用户提供尺寸图，玻璃板名义尺寸29.2 ×59.2mm；未包含完整FPC、后置驱动电路的供应商 STEP。
- 装配全局方向：X横向、Z上下，USB为-Z底边、开关为+X右侧、背面NFC标识为+Y。

## 校验
- 前框、后壳均为单个有效 B-Rep 实体。
- 前框/后壳分别与驱动板、已变换的XIAO、玻璃占位体的实体相交体积：0 mm³。
- 装配 STEP 文件已重新导入测试；独立外壳及压片 STL 经网格顶点合并后为封闭网格。
- XIAO 垂直插接高度由两侧插针和板体包络推定，**仅为概念装配定位，不是经过厂商 mating datum、插针插入深度/电气接触确定的最终装配**。
- “实体不干涉”不等于开关、USB插头或显示FPC真正可操作，也不包含插头外壳包络、螺钉头和粘贴天线的校验。

## 必须实物核查的事情（试打印前）
1. 实际 XIAO 模块在底座中插入的姿态/高度、USB-C 插头的外壳尺寸和插入深度；必要时调整 USB 口。
2. 开关真实拨杆所在区域和开关行程。当前采用右侧手指可触及窗口，**并未凭空设计一个和拨杆绑定的可操作延长杆**。
3. 三个孔的真正机械用途、周围走线和可用螺钉规格；扩展板板边邻壁间隙。
4. ePaper 实物 FPC 24pin 排线的折叠、连接器方向及最小弯折半径。
5. 电池、NFC贴纸/线圈和磁吸装置尚无实体模型，需提供尺寸后再次排布。

## Fusion 360 使用
1. 只需上传 `NFC_ePaper_RevD_OneFile_Assembly.step` 一个文件，不需要逐个添加 STL。
2. Browser 展开 Bodies / Components，可分别显示前框、后壳、板子、XIAO，必要时右键 Bodies -> Create Components from Bodies。
3. 可以将前框隐藏来查看开关与 USB；可以用 Inspect -> Interference 检查自定义移动后的关系。
4. STEP 本身是独立实体，不带 Fusion 的 Joint/装配约束；如遇“只读文件：更改不可保存”，属于当前 Fusion 授权/文档访问状态，需要建立有写入权限的设计后再修改。

## 重建代码
`source/build_revD.py` 为 CadQuery 模型代码，两个供应商 STEP 在同目录。运行后在 `source/RevD` 输出新的 STEP 和 STL。优先调整 `BOARD_DX / BOARD_DZ / OUTER_W`，然后重新生成真正由器件几何驱动的开关和 USB 口。
