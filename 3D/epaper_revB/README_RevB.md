# NFC ePaper Enclosure — Rev B 参数化工程预览

## 文件
- `NFC_ePaper_RevB_assembly.step`：整体 CAD（前框、后壳、玻璃包络、供应商扩展板 STEP、四个独立压片）。可直接导入 Fusion 360。
- `front_bezel_revB.step`, `rear_housing_revB.step`, `screen_clip_01.step` ... `04.step`：可独立编辑的 B-rep 几何。
- 对应 `.stl`：打印试装文件。
- `build_revB.py`：CadQuery 参数化源代码；可修改关键数字后重新导出。

## 坐标与实测基础
X：宽，Z：长，Y：厚；+Y 为后盖方向。单位 mm。扩展板维持 STEP 自带坐标原点，原 STEP 已用于几何装配检查。

| 内容 | 参数 | 来源/属性 |
|---|---:|---|
| ePaper 玻璃外形 | 29.20 x 59.20 x 1.00 | 用户工程图名义值，玻璃公差 ±0.20/±0.10 |
| 玻璃座凹槽 | 29.85 x 59.85 | 设计值（各侧余量约 0.325） |
| 显示开窗 | 24.50 x 50.15 | 工程图 EPL border 参考；可见区域如需全显应与实物复核 |
| 外壳占地 | 43 x 72，外圆角 R3 | 设计值 |
| 外壳厚度 | 21（Y = -8 到 +13） | 当前方案，尚不含电池/磁铁 |
| 外框外壳固定孔 | 四角 x=-14.9,21.9 / z=±32 | 设计值，孔径 2.10；后壳试打印孔径 1.64 |
| 扩展板固定候选孔 | (-7.09,20.18), (14.20,20.18), (14.15,2.52) | 从供应商 STEP 圆柱边读取，圆孔直径约 2.5 mm |
| 扩展板板边定位 | x=-10.0,17.0 / z=±14附近 | 设计值，必须校验是否挡元件及 FPC |
| 可拆卸显示压片 | 4 件，侧边短悬臂 + 螺钉 | 独立 3D 打印件，采用螺钉拆装，非弯曲卡扣 |

## 几何布尔检查（以供应商扩展板 STEP 的原点为准）
- `rear_housing` 和厂商扩展板总 STEP：交集体积 0 mm³。
- `front_bezel` 和厂商扩展板总 STEP：交集体积 0 mm³。
- 屏幕包络与前框/后壳：交集体积均 0 mm³。
- 前框、后壳、4 个压片均为 `isValid=True` 的单个连通实体。
- 注意：这不是精密装配公差、受力/疲劳、实际 NFC/RF、热设计或 3D 打印可行性验证。

## 关键未确定项（不能直接宣布可生产）
1. XIAO STEP 的插入方向、母座配合高度尚未由厂商坐标完全确认；本装配不含 XIAO，未校验叠插后的碰撞和整机厚度。
2. 扩展板 STEP 的直径 2.5 mm 孔是三处候选固定孔，不等于厂商授权安装孔；必须查 PCB layout 或看实物，确认是否为电气/工艺孔、附近是否有焊盘/走线；禁在未经确认的孔穿螺钉。
3. 2.5mm 孔配合螺钉最终螺钉头、垫圈、绝缘保护和拧紧空间，尚未验证；支撑柱位置对应孔位，但默认不附金属紧固件。
4. 螺丝尺寸和前框压片安装孔按小型打印自攻孔概念预留，正式制作应按 M1.6/M2 工艺标准核定并增加螺钉头沉孔。
5. 侧面 USB-C 开口、顶部开关开口为位置示意；等待 XIAO 的实际母座插接姿态和机械开关具体型号。
6. ePaper FPC 的柔性折弯方向、长度与避让槽仅预留概念空间；屏幕绝不能在可视区受夹持。压片接触要加软垫并验证有效边缘禁压区。
7. NFC 天线、磁吸、电池未提供 CAD，不能确认信号与磁铁/金属的干扰；当前后壳不会安排磁铁。
8. 前盖采用螺钉拆装、四个独立压片，是可拆卸方案；并非已经验证的塑料弹性卡扣。若需免工具卡扣，应明确制造方式和循环次数。

## Fusion 360
Fusion 360: File > Open > Upload -> 选择 `NFC_ePaper_RevB_assembly.step`。可对 STEP 的 B-rep 启用建模历史继续修改；几何仍以 `build_revB.py` 为主要参数来源。

## 常用后续修改
- 对外观：修改 `outer_w` / `outer_h` （目前 shell 几何函数中的 43、72）、R3、窗口尺寸。
- 对模具/3D 打印：先用真实打印机做 M1.6/M2 孔规试块，再调整孔径、槽配合、壁厚、支撑方向。
