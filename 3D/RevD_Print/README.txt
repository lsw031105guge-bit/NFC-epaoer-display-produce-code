Rev D printable plastic-only models
- rear_case_revd.stl: rear enclosure
- front_frame_revd.stl: front frame
- screen_retainer_01..04.stl: four removable screen retainers

Units: mm. Import all six STLs into a slicer as separate objects. Arrange them on build plate; do NOT print assembled positions. Mesh validation: all six are watertight, volumetric meshes (checked with trimesh). This does NOT certify printer manufacturability, overhang clearance, hardware fits or snap strength.
Before printing, verify actual screw sizes, switch, USB cable clearance, screen FPC fold, PCB openings, and retainers. Use a test print first.
